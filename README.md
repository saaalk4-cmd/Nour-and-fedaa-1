Nour-and-fedaa-1

ChatGPT Version

This is the independent ChatGPT version of the Nour & Fedaa educational Islamic kids app.

This project is completely separate from the Claude version.

Children

- فداء — 5 سنوات
- نور — 3 سنوات

Goal

Create a highly engaging Islamic educational adventure for children with:

- XP
- Stars
- Levels
- Daily quests
- Streaks
- Achievements
- Rewards
- Journey map
- Age-appropriate learning
- Fun animations
- Sound effects
- Parent dashboard
- Offline-first experience

Important

- Do not copy code or assets from the Claude project.
- Keep this repository independent.
- Do not depict prophets or companions.
- No pressure, shame, or comparison between the children.
- Educational content should be simple, respectful, and trustworthy.

Build

The project will use Flutter and GitHub Actions to build the Android APK.
